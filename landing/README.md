# Aurora Landing

Single page. No build. No env vars.

Sponsored by Creignificent LLC.

## Files

- `index.html`
- `styles.css`
- `app.js`

## Open it

Double-click `index.html`, or from this folder:

```
npx --yes serve .
```

## Deploy

Drag the three files into Netlify Drop, or set the Vercel root to this `landing` folder.

Nothing else is required.
